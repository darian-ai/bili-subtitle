# 阶段二：输入与元数据验证及合并标准

## 自动化验证

在仓库根目录依次运行：

```powershell
uv sync --locked --dev
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run pyright
```

全部命令必须返回 `0`。pytest 必须在无网络、无账号环境通过，且分支覆盖率不低于 90%。Windows GitHub Actions 必须运行同一组质量检查。

## 输入解析场景

| 场景 | 期望结果 |
|---|---|
| 规范 BV 和 av 标识 | 生成对应的规范视频引用，不发起多余请求 |
| 标识带首尾空白或 `AV` 前缀 | 按需求规范化；BV 主体字符保持原值 |
| 标识为空、主体非法、aid 非正整数 | 返回可区分的无效输入错误 |
| `bilibili.com`、`www`、`m` 的视频 URL | 解析视频标识和可选 `p`，忽略无关查询参数与片段 |
| URL 带尾随 `/` | 与无尾随 `/` 的同一视频引用等价 |
| URL 含用户信息、显式端口或额外业务路径 | 在网络请求前拒绝 |
| 相似后缀、其他子域或非官方域名 | 在网络请求前拒绝，不跟随其链接 |
| `p` 为空、重复、非整数或非正整数 | 返回无效输入错误 |

## 短链与网络场景

| 场景 | 期望结果 |
|---|---|
| `b23.tv` 跳转到受支持视频 URL | 解析最终视频标识和最终 URL 的 `p` |
| 短链经过允许的有限中间跳转 | 成功解析且不把重定向历史带入领域模型 |
| 跳转到非官方域名或范围外页面 | 立即停止并返回重定向错误 |
| 重定向缺失、循环或超过上限 | 返回明确错误，不无限请求 |
| 元数据请求超时或连接失败 | 返回网络错误，不输出底层请求详情 |
| HTTP 错误、投稿不存在或删除、无权限 | 映射到对应稳定领域错误 |
| 响应不是 JSON、字段缺失或字段类型错误 | 返回平台响应结构错误，不创建半有效模型 |

所有网络场景必须通过 HTTPX 测试替身和脱敏固定响应完成；默认测试期间若发生未声明的真实网络请求，测试必须失败。

## 分集选择场景

| URL `p` | `--page` | `--all-pages` | 期望结果 |
|---|---:|---:|---|
| 无 | 无 | 否 | 按平台顺序选择全部分集 |
| `N` | 无 | 否 | 只选择 P=N |
| 无 | `N` | 否 | 只选择 P=N |
| `M` | `N` | 否 | 只选择 P=N，并提示显式选项覆盖 URL `p` |
| 无 | 无 | 是 | 选择全部分集 |
| `N` | 无 | 是 | 选择全部分集，并提示显式选项覆盖 URL `p` |
| 任意 | `N` | 是 | 在网络请求前返回互斥用法错误 |

还必须覆盖 P 序号不存在、超出范围、元数据分集为空及平台返回重复 P 序号。选择结果不得按 CID 或标题重新排序，也不得包含其他投稿的分集。

## CLI 场景

| 场景 | 期望结果 |
|---|---|
| 单分集投稿解析成功 | 返回 `0`；显示标题、规范 bvid、aid、选择数量、P 序号、CID 和分集标题 |
| 多分集默认调用 | 返回 `0`；逐行显示全部分集且顺序与平台响应一致 |
| URL `p` 或 `--page` | 返回 `0`；摘要中只出现所选分集 |
| 显式选项覆盖 URL `p` | 返回 `0`；摘要前出现简短覆盖提示，且不回显完整 URL |
| 无效输入或无效分集 | 返回 `2`；错误类别和原因明确，不创建 `subtitles/` |
| 投稿不存在、无权限或平台异常 | 返回 `2`；提示可区分且不透传响应正文 |
| `auth login|status|clear` | 继续返回阶段占位结果，不触发阶段二网络流程 |
| 使用 `--lang` 或 `--force` | 元数据选择不受影响，不执行字幕过滤或文件写入 |

纯文本摘要的字段标签、分集行结构和顺序必须由 CLI 测试锁定。测试还应包含带换行或终端控制字符的伪标题，确认其不能伪造额外输出行。

## 模型与架构检查

- 视频引用只包含 bvid 或 aid 之一，并保留可选 URL 页码。
- 视频元数据同时包含正整数 aid、规范 bvid、标题和不可变有序分集。
- 每个分集包含正整数 P 序号、正整数 CID 和标题；重复 P 序号被拒绝。
- 领域层不得导入 Typer、Rich、HTTPX 或 Bilibili 适配器。
- CLI 不直接发送 HTTP 请求，适配器不直接打印终端消息。
- 平台接口路径、结果码和响应字段解析集中在基础设施层。

## 无副作用与安全审计

- 默认测试不得访问真实网络、读取 Windows Credential Manager 或使用真实 Cookie。
- 阶段二命令不得创建 `subtitles/`、JSON、SRT、manifest 或临时业务文件。
- 捕获输出、异常、测试快照和固定响应不得包含 Cookie、二维码密钥、签名 URL、完整重定向历史或账号数据。
- 错误提示不得直接包含平台响应正文或未经控制的远端消息。
- 直接运行时新增依赖只能服务于阶段二 HTTP 能力，不得出现 keyring、qrcode、媒体下载、ASR、OCR 或访问控制绕过工具。

## 可合并条件

- 上述自动化验证、输入、短链、网络、选择和 CLI 场景全部通过。
- [`requirements.md`](./requirements.md) 的范围、输入契约、领域模型和已确定决策均有实现或测试保护。
- 单分集和多分集投稿都能得到正确、稳定、有序的选择结果。
- 无效输入、无效分集和各类平台异常具有明确且安全的结果。
- 实现没有自动扩展到其他投稿，也没有提前加入登录、字幕或导出能力。
- 锁文件、feature spec 和实现保持一致，工作区除本 feature 的预期文件外没有无关改动。
