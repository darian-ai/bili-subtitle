# 阶段二：输入与元数据实施计划

## 1. 建立阶段二模块边界与依赖

- [x] 将 HTTPX 加入运行时依赖并更新锁文件，不提前加入认证或字幕阶段依赖。
- [x] 创建输入与分集选择的应用层、视频元数据领域模型和 Bilibili 基础设施适配层。
- [x] 定义应用层使用的元数据端口，使领域和应用逻辑可用测试替身离线验证。
- [x] 保持 CLI → 应用层 → 领域/基础设施层的单向依赖，禁止领域层导入框架或平台代码。

## 2. 实现输入解析与规范化

- [x] 解析并规范化裸 BV、av 标识及首尾空白和允许的前缀大小写差异。
- [x] 解析受支持的官方完整视频 URL，严格校验 scheme、host、port、path 和视频标识。
- [x] 解析唯一且为正整数的 URL `p`，忽略其他无关查询参数和片段。
- [x] 为无效标识、URL 边界和查询参数建立参数化纯函数测试。

## 3. 建立视频与分集领域模型

- [x] 定义视频引用、视频元数据、分集和分集选择的不可变数据模型。
- [x] 定义无效输入、无效分集、投稿不存在或删除、无权限、网络、重定向和响应结构错误。
- [x] 使用显式构造校验保护正整数 aid、P 序号、CID、规范 bvid 和唯一分集序号。
- [x] 测试领域层不依赖 Typer、Rich、HTTPX 或 Bilibili 响应对象。

## 4. 实现 Bilibili 元数据适配器

- [x] 配置复用的同步 HTTPX Client、统一请求头、连接与读取超时，不读取真实登录凭据。
- [x] 按 bvid 或 aid 请求视频元数据，集中处理 HTTP 状态、平台结果码和响应结构校验。
- [x] 在限制次数和官方域名的条件下解析 `b23.tv` 重定向，并重新使用完整 URL 解析器校验最终地址。
- [x] 把平台响应转换为有序领域模型，把平台失败映射为稳定领域错误。
- [x] 使用单分集、多分集和各类异常的脱敏固定响应完成 HTTP 模拟测试。

## 5. 实现分集选择应用流程

- [x] 在网络请求前拒绝同时使用 `--page` 与 `--all-pages`。
- [x] 实现显式选项、URL `p` 和默认全部分集的优先级规则。
- [x] 显式选项覆盖 URL `p` 时生成结构化提示信息，不在领域层直接打印。
- [x] 校验指定 P 序号真实存在，并保持全部或所选分集的平台原始顺序。
- [x] 测试单分集、多分集、默认全部、显式覆盖、互斥和越界行为。

## 6. 接入 CLI 与稳定摘要

- [x] 用阶段二应用流程替换主提取命令的占位行为，认证命令仍保持占位。
- [x] 输出固定字段的投稿摘要和逐行分集摘要，并安全处理标题中的终端控制字符。
- [x] 显示 URL `p` 被覆盖的简短提示，不回显完整 URL 或重定向链。
- [x] 将分类领域错误映射为可区分的简体中文提示和退出码 `2`。
- [x] 验证 `--lang` 和 `--force` 不触发阶段外行为，也不创建输出目录。
