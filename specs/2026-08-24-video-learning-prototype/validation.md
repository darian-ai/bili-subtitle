# 阶段九：Chrome/Edge 视频学习原型验证及合并标准

## 自动化门禁

- Python 测试、分支覆盖率不低于 90%、strict Pyright、Ruff、构建、隔离安装和 `git diff --check` 全部通过。
- Extension 执行 `npm ci`、lint、typecheck、Vitest、Playwright 及 Chrome/Edge 构建，OpenAPI client 无漂移。
- 默认测试封锁真实 Bilibili、模型、Credential Manager 和用户知识库；现有 V1 与阶段八回归全部通过。

## API 与安全

以下场景均有自动化测试：配对成功、过期、重复使用、错误 Origin；token 缺失、错误和撤销；非法 Host/CORS/内容类型/schema/请求大小；端口冲突及未知异常脱敏。

- 服务仅监听 `127.0.0.1`，除健康检查外无匿名业务接口。
- 长任务返回 `202 + job_id`，状态转换合法；失败、中断和重启后不得伪装完成。
- job 进度使用稳定阶段和 0–100 百分比，运行期间单调递增，终态为 100%，重启恢复后仍合法。
- 日志、响应、扩展存储、数据库和构建产物不含秘密金丝雀。

## Extension 与交互 E2E

Playwright 使用模拟视频页和假 Local API 覆盖：

- 首次配对、断线、重新连接、SPA 导航和不支持页面。
- BV/P/当前时间识别、单/多轨选择、无字幕与访问失败区分。
- 用户主动生成、阶段进度、轻量大纲、章节跟随和独立按需详情页。
- 大纲、练习、笔记底部导航；大纲页不得同时渲染详情、全部问题和回答框。
- 按章节生成并展示练习、时间戳笔记、回答/复述、证据反馈和点击跳转；跳转误差不超过两秒。
- 正文默认 18px，内容填满并响应用户调整后的侧栏宽度，控件在窄侧栏不产生横向溢出。
- 页面刷新与服务重启后恢复，重新生成和任务失败不覆盖个人笔记。
- 未经点击不发起模型请求，不自动暂停、弹题或遮挡视频。

## 内容与持久化

- 短、长字幕均覆盖首尾 cue，所有公开事实和反馈引用当前 revision 的合法证据。
- 正文预算内且不超过 800 cue 的字幕只发起一次轻量大纲模型请求；超限字幕才使用 map/reduce。
- 章节详情和练习证据只能落在对应章节；首次无效输出修复成功或第二次稳定失败，失败内容不得持久化。
- 无证据时明确无法判断；字幕中的伪指令不能改变安全或输出约束。
- job、指南、详情、练习和笔记重启可恢复；schema migration 保持旧指南可读，AI Markdown 可重建，个人 Markdown 保持独立且不可覆盖。

## 真实脱敏验收

在 Chrome 与 Edge 使用真实 Bilibili 字幕和用户自备 OpenAI-compatible Provider，验证短/长视频、多 P、人工/AI 字幕、多轨道及无字幕场景，并走通配置、登录、服务、配对、轻量大纲、详情、按章练习、笔记、复述和回看。记录优化前后脱敏的模型请求数与耗时范围，并验证生成时可导航及用户可拖动宽度。

只记录环境、命令形态、耗时范围和通过/失败；不得记录 BV、标题、账号、字幕、Prompt、响应、笔记或 Key。
