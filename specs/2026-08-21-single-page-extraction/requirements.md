## 背景与目标

阶段二已经能把输入解析为投稿与确定分集，阶段三已经能安全取得并复用登录会话。阶段四建立最小但完整的字幕数据路径：对一个已经确定的普通 UGC 分集，发现当前账号可见的播放器字幕轨道；对一个明确选定的轨道立即下载正文；保存接口返回的原始 JSON；从同一响应按原顺序生成 UTF-8 SRT；最后写出描述本次结果的 manifest。

本阶段的重点是验证数据忠实性、平台边界、原子写入和秘密隔离。它提供阶段五可串行编排的单分集、单轨道能力，但不提前实现多分集、全部轨道、语言过滤、重复运行策略或局部失败汇总。

## 范围

- 为人工字幕与 AI 字幕建立不可变轨道模型，保留平台语言代码、显示名称、轨道 ID 和轨道属性。
- 通过播放器字幕接口发现一个确定分集的有序可见轨道列表。
- 在基础设施适配器内部短暂持有带签名正文 URL，并在发现后立即使用同一个同步 HTTPX Client 下载。
- 严格校验字幕正文的 HTTP 状态、JSON 结构、片段时间与文字字段。
- 原样保留字幕正文响应字节，并从同一响应解析得到的片段生成 SRT。
- 使用同目录临时文件与原子替换安全写入原始 JSON、SRT 和 manifest。
- 为一个明确的分集与一个明确的轨道产出稳定的三文件闭环。
- 区分无字幕、需登录、不可访问、网络失败和平台响应结构异常。
- 使用脱敏固定响应完成离线自动化测试，不访问真实网络或真实 Credential Manager。

## 单分集、单轨道边界

- 应用层接收阶段二已确定的 `VideoMetadata`、一个 `VideoPage` 和阶段三已验证的会话上下文，不重新解析输入或选择分集。
- 轨道发现返回平台顺序不变的不可变轨道集合；空集合是“无字幕”的正常领域结果，不是结构错误。
- 单轨道提取入口只能处理由本次发现结果明确选定的一条轨道；不得猜测语言、合并轨道或按“最优字幕”隐式替用户选择。
- 阶段四通过应用服务与适配器集成测试证明纵向闭环。主命令仍保持阶段三的元数据摘要行为，直到阶段五能够一次实现 Mission 要求的默认全部分集、全部可见轨道与失败隔离，避免发布临时的“只取第一条”行为。
- 阶段五只能编排本阶段的单元能力，不应改变轨道正文、SRT 和安全写入的语义。

## 轨道模型与发现契约

- `SubtitleTrack` 至少表达轨道 ID、平台语言代码、平台显示名称和 `HUMAN`/`AI` 类型；字段进入领域层前必须完成严格类型与非空校验。
- AI 属性只描述平台已经提供的轨道，不代表本工具生成、识别或修正字幕。
- 轨道顺序严格保持播放器响应顺序；同语言、同名称的多个轨道仍以轨道 ID 区分，不去重或覆盖。
- 轨道 ID 仅作为稳定身份与输出名组成部分，不作为正文下载地址。
- 带签名的正文 URL 不得进入 `SubtitleTrack`、其他领域模型、应用结果、manifest、日志、异常、测试快照或文件名。
- 播放器响应缺少字幕区可判定为无字幕；顶层、字幕列表或轨道字段类型异常必须判定为平台响应结构异常，不得静默当作空列表。

## 临时签名 URL 与正文下载

- 播放器适配器在一次短生命周期操作中解析轨道描述和对应正文 URL；正文 URL 只存在于基础设施层私有局部对象或调用栈中。
- 选定轨道后必须立即下载，不缓存、不序列化、不跨进程保存，也不返回给 CLI 或领域层。
- 若平台返回协议相对 URL，仅允许明确补全为受支持的 HTTPS Bilibili 域；拒绝非 HTTPS、用户信息、异常端口和非受信任主机。
- 下载使用已有同步 HTTPX Client、统一超时、Cookie 和请求头；不并发，不盲目重试签名失效、权限或结构错误。
- HTTP 401/鉴权失效映射为需登录；403 或明确权限拒绝映射为不可访问；超时、连接失败和服务端瞬时错误映射为网络失败；其他非法状态或载荷映射为平台响应结构异常。
- 错误只给出稳定分类，不附带请求 URL、查询参数、响应正文、Cookie 或请求头。

## 原始 JSON 与字幕片段

- “原始 JSON”指字幕正文接口本次成功响应的原始字节；通过校验后按字节不变写入 `.json`，不得重新序列化、缩进、排序键或改变转义。
- 响应必须能按 UTF-8 解析为 JSON 对象，并包含有序字幕片段列表；布尔值不得冒充数值。
- 每个字幕片段至少包含非负有限起始秒、非负有限结束秒和字符串正文；结束时间不得早于开始时间。
- 正文允许空格、换行、空字符串以及平台返回的任意 Unicode 文本；不得 `strip`、翻译、润色、补标点、繁简转换、合并或拆分。
- 片段严格按平台响应顺序保留，不自动排序，也不因时间重叠或相同时间戳而合并。
- 额外 JSON 字段在原始文件中完整保留，但不进入无必要的长期领域模型。

## 忠实 SRT 契约

- SRT 条目编号按原始片段顺序从 1 递增。
- 时间转换使用 `HH:MM:SS,mmm`；非负十进制秒值乘以 1000 后采用 `ROUND_HALF_UP` 得到整数毫秒，避免二进制浮点与银行家舍入差异，不借此调整相邻片段边界。
- 每条 SRT 正文与 JSON 正文字段逐字符一致；内部换行原样保留，不追加或删除正文空白。
- 只增加 SRT 格式自身必需的编号行、时间行、条目分隔空行和文件编码，不执行任何文本处理。
- SRT 使用 UTF-8；测试必须覆盖小数秒边界、超过一小时、Unicode、标点、前后空格、内部换行、重叠和输入顺序。

## 输出与安全写入

- 阶段四测试与应用服务显式接收输出目录及已经确定的文件基名；完整 Windows 文件名净化、路径长度、冲突消解和默认目录编排属于阶段五。
- 闭环输出为 `<基名>.json`、`<基名>.srt` 和输出目录内的 `manifest.json`。
- 每个目标先在同目录创建唯一临时文件，完整写入、刷新并关闭后再以原子替换发布；失败时清理临时文件，不留下可被误认为成功的目标。
- 三个目标分别安全发布；manifest 必须最后写入，且只把已经成功发布的 JSON/SRT 记录为成功。
- 本阶段调用方必须提供不存在的目标路径，避免提前定义阶段五的逐文件跳过、缺失补齐和 `--force` 覆盖策略；意外存在目标时明确失败且不得覆盖。
- 原始 JSON 按字节写入；SRT 与 manifest 使用 UTF-8，manifest 为确定性 JSON，便于测试和后续扩展。

## manifest 最小契约

- manifest 记录 schema 版本、视频 bvid/aid/标题、分集 P 序号/CID/标题、轨道 ID/语言/显示名称/人工或 AI 属性、JSON/SRT 相对文件名和处理结果。
- manifest 不保存绝对路径、Cookie、二维码信息、请求头、播放器响应、签名 URL 或正文下载来源。
- 结果只有在 JSON 和 SRT 均成功发布后才标记成功；写 manifest 失败必须作为导出失败报告，但不得删除已经成功发布的字幕文件。
- manifest 字段采用稳定技术标识；解释、状态和错误仍使用简体中文。
- 阶段五扩展 manifest 以容纳多个分集和轨道时，必须保持本阶段的身份字段、安全禁项和成功含义。

## 错误分类与结果

- `NoSubtitles`：播放器明确返回空字幕集合；正常结果，不伪装成网络或权限失败。
- `AuthenticationRequired`：会话无效或接口明确要求登录；允许上层按阶段三规则处理，但本阶段自身不启动二维码循环。
- `SubtitleAccessDenied`：当前账号通过正常流程不可访问；不得加入替代私有接口或绕过。
- `NetworkError`：连接、超时或明确服务端网络故障。
- `PlatformResponseError`：响应不是当前支持的合法结构、URL 不安全或正文校验失败。
- `ExportError`：目录、临时文件、替换或 manifest 写入失败；消息不得包含文件内容或秘密。
- 单轨道应用结果显式表达成功、无字幕或分类失败，供阶段五以后聚合；阶段四不定义完整 V1 的 `0|1|2` 汇总算法。

## 已确定决策

1. 原始 JSON 保存网络响应原始字节，解析对象只用于严格校验和 SRT 转换。
2. 签名 URL 属于基础设施层瞬时能力，不使用包含 URL 的公开 DTO，也不以简单日志脱敏代替结构隔离。
3. 空字幕列表与异常结构严格区分；只有结构合法且列表为空才是无字幕。
4. SRT 保持平台片段顺序与正文逐字符一致，只进行格式必需的时间表示转换。
5. manifest 最后写入并仅记录已发布结果；manifest 失败不会回滚已成功字幕文件。
6. 阶段四不把不完整的单轨道策略接入公开主命令；阶段五一次完成 Mission 的完整选择与汇总契约。
7. 本阶段不引入新运行时依赖；标准库 JSON、pathlib 与现有 HTTPX 足以完成闭环。

## 不在范围内

- 多分集串行编排、默认全部分集或 `--all-pages` 的字幕处理。
- 一个分集内全部轨道处理、`--lang` 重复过滤及同语言多轨道冲突处理。
- 已有文件逐个跳过、缺失项补齐、`--force` 覆盖和重复运行摘要。
- Windows 文件名净化、保留名称、冲突消解、路径长度控制和最终默认目录树。
- 分集级/轨道级失败隔离、继续处理、最终摘要及 `0|1|2` 退出码聚合。
- 翻译、双语合并、字幕校正、ASR、OCR、视频/音频下载或任何访问控制绕过。
- 番剧、影视、课程、互动视频或其他非普通 UGC 内容。

## 安全与兼容约束

- 默认测试不得联网、读取真实 Credential Manager、真实等待或依赖用户账号。
- 固定响应和测试数据只含明显伪值，不提交真实字幕签名 URL、Cookie、账号或响应正文。
- 用唯一伪签名 URL 与伪 Cookie 作金丝雀，断言输出、异常、`repr`、manifest、文件名和测试快照均不包含它们。
- 领域层只使用标准库，不导入 Typer、Rich、HTTPX、keyring 或具体平台代码。
- CLI 不直接发现轨道、下载正文或写文件；平台字段和 URL 校验集中在 Bilibili 适配层。
- 代码库不得出现媒体下载、FFmpeg、ASR、OCR、WBI、APP 私有接口或绕过路径。
