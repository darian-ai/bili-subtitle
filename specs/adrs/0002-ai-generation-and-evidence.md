# ADR 0002：AI 生成与证据

- 日期：2026-08-21
- 状态：Accepted
- 关联：[`mission.md`](../mission.md)、[`tech-stack.md`](../tech-stack.md)、[`阶段七 Feature`](../2026-08-21-v2-compatibility-baseline/requirements.md)

## 上下文

长字幕不能安全截断，模型输出也不能天然视为可信事实或合法引用。

## 决策

Provider 使用 OpenAI-compatible 边界；只有用户主动操作才上传字幕。完整字幕以覆盖全部 cue 的 Map/Reduce 生成大纲，章节详情按需生成。输出必须通过版本化严格 schema、cue/时间范围和覆盖校验；结构失败只允许一次受约束修复。字幕属于不可信数据，Prompt injection 不得改变工具、权限、上传或证据规则。

## 替代方案

拒绝静默上传、固定截断、一次性长上下文、自由 Markdown 和无法映射到 cue 的引用。

## 后果

实现需要可复现指纹、固定响应评测和明确的 Provider 错误分类；相比自由文本生成，会增加 schema、分块、修复和引用验证成本。

## 安全与隐私影响

字幕和模型输出均按不可信数据处理，模型不得获得网络、文件或系统工具。用户必须在上传前知道 Provider、模型和数据范围；日志、异常与缓存键不得包含 API Key 或字幕正文。

## 后续阶段约束

阶段七不调用模型。阶段八必须先实现完整 cue 覆盖、严格证据校验、一次修复上限和固定响应评测；阶段九只能展示通过本地验证的内容。放宽证据或主动上传边界需要新的 ADR。
